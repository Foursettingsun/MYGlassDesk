# MYGlassDesk

基于 GlassDesk 1.5.2 本机安装版本保存的修改版，面向 Windows x64。仓库包含可直接运行的程序、随附的 .NET 10 / WPF 运行时、当前外观设置、修补工具源码及原有许可证。

**这是运行版本与修补源码的归档，不是原项目的完整源码仓库。** 本次修改是在已安装的程序集上，通过 Mono.Cecil 写入修补逻辑完成的；部分 `.inspect.cs`、`.current.cs` 和 `decompiled` 文件是分析时反编译得到的参考代码，不代表一套能够直接构建整个应用的解决方案。

## 运行

1. 使用 Git 克隆仓库，或下载 ZIP 后完整解压。
2. 在可写的本地目录运行 `GlassDesk.exe`，保留同目录的 DLL、资源和许可证文件。
3. 首次运行后按需添加自己的应用，并设置 Dock 和启动台布局。

程序已随附运行时，无需单独安装 .NET SDK。运行与修改工具源码是两种不同用途：修补工具的项目使用 .NET 8 SDK 和 Mono.Cecil 0.11.6，部分材质与布局辅助代码需要引用本目录的 .NET 10 / WPF 程序集。

仓库不保存本机应用清单、个人分页布局、图标缓存、快捷方式、日志、旧版二进制备份及临时构建产物。`Data/settings.json` 保留本次调整后的设置；其他用户数据由程序运行时生成。

## 已包含的修改

- 固定桌面层：Dock 常驻桌面层，应用窗口可覆盖 Dock；关闭自动隐藏。
- 运行指示点：创建图标及刷新运行状态时均遵守关闭指示点的设置。
- 悬浮放大：实际放大峰值由 1.15 调整为 1.38，即比原来的悬浮尺寸增加 20%。原有 `magnificationPeak` 配置字段在这一版中未参与该计算。
- 启动台液态玻璃：先准备首帧材质，再开始显示动画，并衔接到实时背景，修复冷启动及休眠后打开时的闪烁。
- 启动台分页：当前页未填满时也能将图标拖到下一页，并保存手动分页边界；支持分组布局。
- 应用匹配：为 ChatGPT / Claude 快捷方式保留 AppUserModelId，避免把 Explorer 窗口误认为目标应用。对应快捷方式创建与检查源码为 `Data/recovery/repair-tools/AppLinks.cs`；本机快捷方式不随仓库分发。
- 拖动删除区域：宽高由 76×58 缩至 38×29，移到启动台左上角，避免占用应用图标区域。
- Dock 内置操作：点击“此电脑”或“切换桌面图标”时收起已打开的启动台；启动台已关闭时不会误打开。

将两个快捷方式放入各自应用安装根目录的后续请求尚未实施：两者安装在受保护的 WindowsApps 目录，系统拒绝写入。该失败操作未改变快捷方式绑定。

## 修补源码与验证

修补源码在 `Data/recovery/` 下，按问题保存；`repair-tools/` 中保留了分页、删除区域和 Dock 内置操作的工具项目，以及快捷方式检查代码。原始完整源码和各补丁所需的原始 DLL 不包含在该目录中，不能仅通过执行一个项目重新构建整个应用。

当前 DLL 已应用全部修补。多数补丁工具有重复修补检查，请勿直接对运行中的文件重复执行历史补丁。后续修改前应先备份，并根据现有程序集状态调整工具。

既有验证结果及当前文件校验方式见 [VERIFICATION.md](VERIFICATION.md)。`runtime-manifest.json` 记录本次归档运行文件的 SHA-256，可用于确认下载后的文件完整性。
