# MYGlassDesk

一个基于 **GlassDesk 1.5.2** 调整的 Windows 桌面工具，提供玻璃风格的 Dock 和启动台，用于整理、查找和启动应用。

[**下载安装包 · Windows x64 · 约 55 MiB**](https://github.com/Foursettingsun/MYGlassDesk/releases/latest/download/GlassDesk-1.5.2-Modified-Setup.exe)

[查看发布说明与历史版本](https://github.com/Foursettingsun/MYGlassDesk/releases)

## 功能介绍

- **桌面 Dock**：固定常用应用，提供“此电脑”、启动台和桌面图标切换入口。
- **应用启动台**：支持搜索、分组、文件夹、拖动排序和分页整理。
- **玻璃外观**：支持液态玻璃等材质，可调整透明度、圆角及图标大小。
- **固定桌面层**：Dock 保持展开，普通应用窗口可以覆盖它。

## 本修改版的调整

| 项目 | 调整内容 |
| --- | --- |
| Dock 显示 | 启用固定桌面层并关闭自动隐藏。 |
| 运行指示点 | 关闭图标下方的应用运行小点，并修复刷新状态时仍然显示的问题。 |
| 悬浮放大 | 悬浮尺寸比原效果增加 20%，放大峰值由 1.15 调整为 1.38。 |
| 玻璃首帧 | 启动台先准备好玻璃材质，再播放打开动画，并过渡到实时背景，减少久未打开后的闪烁。 |
| 拖动分页 | 当前页未满时，也能把图标拖到下一页，并保存分页边界。 |
| 删除区域 | 删除区域宽高缩小 50%，移到启动台左上角，避开应用图标区域。 |
| 内置入口 | 打开启动台后，点击 Dock 的“此电脑”或“切换桌面图标”会同时收起启动台。 |
| 快速点击 | 动画收起期间再次点击可以重新展开；动画和材质准备不再占用 Dock 按钮区域，取消打开后不会被旧任务重新弹出。 |
| 首次响应 | 启动空闲时预先加载窗口、图标和材质，鼠标移入启动台按钮时按需预热，减少首次点击后的准备工作。 |

## 安装与使用

1. 下载上方的 `GlassDesk-1.5.2-Modified-Setup.exe`。
2. 运行安装程序，选择安装目录并完成安装。
3. 启动 GlassDesk，添加自己的应用，按需设置 Dock 和启动台。

支持 **Windows 10 22H2 / Windows 11，x64 架构**。安装包已包含 .NET 10 / WPF 运行库，无需额外安装 SDK。

已有 GlassDesk 的用户可选择原目录覆盖安装。安装程序会保留已有的 `Data/settings.json`；本修改版的默认设置用于新安装，已有配置可在设置中自行调整。

拖动图标至启动台右边缘并稍作停留，即可切换或新建下一页。

## 包内内容

安装包包含运行程序、所需运行库、默认设置及许可证。个人应用列表、个人布局、图标缓存和 ChatGPT / Claude 等本机快捷方式均未打包；安装后请添加自己的应用。
